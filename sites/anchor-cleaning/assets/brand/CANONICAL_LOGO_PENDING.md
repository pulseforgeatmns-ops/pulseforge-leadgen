# Canonical logo — pending source asset

**Status:** `TEMPORARY_PENDING_CANONICAL_LOGO`

The approved **gold Anchor polo logo** is the only acceptable brand mark for:

- favicon.ico / SVG / PNG variants
- Apple touch icon
- web app manifest icons
- JSON-LD `logo`
- Open Graph link preview
- Twitter/X link preview

## Required source file (not in repository)

Provide one of:

| File | Spec |
|---|---|
| `anchor-logo-canonical.svg` | Preferred vector export from approved polo artwork |
| `anchor-logo-canonical.png` | 1024×1024 minimum, transparent background, exact polo mark |

Do **not** redraw, approximate, or substitute the inline clip-art SVG used in page headers.

## After the canonical file is added

1. Export favicon ICO/SVG/PNG, apple-touch-icon (180×180), manifest icons (192, 512)
2. Build `social-preview-vNEXT.jpg` (1200×630) — deep navy, cream, approved gold logo, restrained type
3. Bump `BRAND_ASSET_VERSION` in `index.html`, `residential/index.html`, and `site.webmanifest`
4. Add `"logo": "https://goanchorcleaning.com/assets/brand/anchor-logo-canonical.png?v=NEXT"` to JSON-LD on both pages
5. Replace header wordmark SVG with the canonical mark
