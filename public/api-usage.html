    Spending controls

    Limits apply across all tenants for each provider. They count paid attempts, including failures and in-flight work. Cache hits do not use an allowance. Resets use UTC.

    Dollar limits use conservative estimates. Max can tighten limits or pause a provider. An operator can raise limits or resume it. Blank fields mean no limit; zero blocks paid requests.

    No limits are selected automatically. A stopped request does not restart by itself; a later scheduled run must try again.
