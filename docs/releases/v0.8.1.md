# Release v0.8.1 — Temporal Intelligence & Memory

| Field | Value |
|---|---|
| **Status** | Shipped (library) |
| **Date** | 2026-07-26 |
| **Spec** | [SPEC-003 Temporal Intelligence & Memory](../specs/SPEC-003_Temporal_Intelligence_Memory.md) |

## Goals

- Persist deterministic reasoning snapshots (append-only)
- Diff snapshots and detect meaningful transitions
- Expose memory queries and watch registration (detection only)
- Keep reasoning core unchanged; no LLM; agents unwired

## Included

- `packages/max/memory/` — SnapshotEngine, DiffEngine, ChangeDetector, TimelineBuilder, WatchRegistry, RecommendationEvolution, TemporalExplanationEngine, MemoryEngine
- Snapshot repositories: InMemory + Serializing (parity)
- APIs: `remember`, `whatChanged`, `whyChanged`, `history`, `trend`, `scoreHistory`, `confidenceHistory`, `evolve`, `watch`
- Tests under `packages/max/memory/tests/` (included in `npm run test:max`)

## Not included

- Notifications / briefing copy
- Dashboard UI
- Runtime agent wiring
- Postgres-backed snapshot store

## Upgrade notes

Additive only. `createMaxReasoningRuntime()` now also returns `memory` and `remember()`. Existing `evaluate()` behavior unchanged.
