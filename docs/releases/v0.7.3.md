# Release v0.7.3 — Persistent Knowledge Store

| Field | Value |
|---|---|
| **Status** | Shipped (library) |
| **Date** | 2026-07-26 |
| **Spec** | [SPEC-001 Persistent Knowledge Store](../specs/SPEC-001_Persistent_Knowledge_Store.md) |

## Goals

- Persist the knowledge graph in Postgres behind the existing `GraphRepository` contract
- Keep `KnowledgeService` unchanged

## Included

- Migration `2026-07-26-knowledge-graph-persistent.sql`
- `PersistentGraphRepository`
- Postgres tests (`npm run test:knowledge:postgres`)

## Not included

- Agent/server dual-write
- Neo4j or other graph databases
- KnowledgeService API changes

## Upgrade notes

Apply migration explicitly (`npm run db:migrate`) when ready to use Postgres-backed knowledge. Default runtime still uses in-memory unless a persistent repository is injected.
