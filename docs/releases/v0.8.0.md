| Field | Value |
|---|---|
| **Status** | Shipped (library) |
| **Date** | 2026-07-26 |

## Goals

- Deterministic, evidence-backed recommendations over the Knowledge Graph
- Modular strategies with weighted aggregation and independent confidence
- First-class contradictions and explainability chains
- No LLM; no agent/server wiring

## Included

- Package `packages/max/`
  - `ReasoningContextBuilder`, Strategy Registry, seven strategies
  - `ScoreAggregator`, `RecommendationBuilder`, `ExplanationEngine`, `ReasoningReport`
  - `ReasoningEngine.evaluate()` → recommendation + explanation + report
- Tests: `npm run test:max` (strategies, aggregation, contradictions, determinism, snapshots, explanation, performance)

## Not included

- LLM prompting / NL summaries
- Autonomous execution / outbound
- Dashboard UI
- Runtime agent wiring (Max briefing / shadow orchestration unchanged)
- Remaining Business KG production ingest / shadow dual-write (still draft under SPEC-001)

## Upgrade notes

Additive library only. Require via `packages/max` or `@pulseforge/max`. Default production runtime unchanged.
