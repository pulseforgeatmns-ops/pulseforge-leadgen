## Goals

- Present the full intelligence stack as one immutable `CommandDeckModel`
- Keep the UI render-only — no ranking, merging, or empty-state invention in the browser
- Expose a single API: `GET /api/v1/command-deck`

## Included

- `packages/max/commandDeck/` — CommandDeckComposer, IntelligenceCard contract, empty states, section composers
- API: `max.compose({ tenantId, asOf, period })`
- HTTP: `GET /api/v1/command-deck` (`routes/commandDeck.js`)
- Assembles Morning Brief, Highest Leverage Action, Watch Alerts, Market Trends, Priority Queue
- Explainability metadata on every card (`sources`, `reasoningId`, `policyId`, `briefingId`)
- Tests under `packages/max/commandDeck/tests/` (included in `npm run test:max`)

## Not included

- Command Deck UI / styling (SPEC-006)
- Ask Max modal
- Knowledge dual-write / live Scout sync into the composer runtime
- Autonomous execution

## Upgrade notes

Additive only. `createMaxReasoningRuntime()` now also returns `commandDeck` and `compose()`. Existing `evaluate()` / `remember()` / `brief()` / `decide()` behavior unchanged.
