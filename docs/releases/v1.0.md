## Goals

- Command Deck landing (`/command-deck`): Morning Brief, Highest Leverage Action, Priority Queue, Ask Max launcher (SPEC-008)
- Conversation (Ask Max workspace) is investigation over KG + Max — not navigation (SPEC-006)
- Mature approval and outbox loops for **authorized** tenants
- Product experience matches Mission / Product Experience / Constitution §11
- Operators understand market state in under 30 seconds and can inspect the full evidence chain

## Non-goals for v1.0

- Fully autonomous multi-channel campaigns without approval
- Replacing human setters/closers
- Cross-tenant intelligence
- Recreating intelligence logic in the UI

## Exit criteria

- SPEC-008 acceptance criteria pass (render-only Command Deck)
- SPEC-006 acceptance criteria pass (Ask Max workspace, explainability pages, intelligence-first nav)
- A new contributor can operate from docs + Command Deck without chat archaeology
- Constitution (approval, explainability, tenancy, DNC, cognitive load) enforced in the primary flows
- CURRENT_STATE reflects a stable v1.0 maintenance posture
