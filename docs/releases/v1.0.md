# Release v1.0 — Conversation-First Operating Partner

| Field | Value |
|---|---|
| **Status** | Planned |
| **Depends on** | v0.7–v0.9 capability line |

## Goals

- Conversation surfaces over KG + Max reasoning
- Mature approval and outbox loops for **authorized** tenants
- Product experience matches Mission / Product Experience principles
- Operators can run day-to-day attention + outreach with explainable recommendations

## Non-goals for v1.0

- Fully autonomous multi-channel campaigns without approval
- Replacing human setters/closers
- Cross-tenant intelligence

## Exit criteria

- A new contributor can operate from docs + conversation/UI without chat archaeology
- Constitution (approval, explainability, tenancy, DNC) enforced in the primary flows
- CURRENT_STATE reflects a stable v1.0 maintenance posture
