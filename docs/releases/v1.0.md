## Goals

- Command Deck landing (`/command-deck`): Morning Brief, Highest Leverage Action, Priority Queue, Ask Max launcher (SPEC-008)
- Conversation (Ask Max workspace) is investigation over verified Structured Response Objects — LLM presentation only (SPEC-009 / ADR-005)
- Continuous intelligence graph: trail, Related Intelligence, Company + Recommendation destinations (SPEC-010)
- Living intelligence: soft evolution, Max awareness, material notifications (SPEC-011 / ADR-006)
- Operator learning: adaptive presentation + Max suggestion personalization without changing facts (SPEC-012 / ADR-007)
- Outcome learning: measure recommendation success, calibrate confidence, detect drift — evaluate only (SPEC-013 / ADR-008)
- Mature approval and outbox loops for **authorized** tenants
- Product experience matches Mission / Product Experience / Constitution §11
- Operators understand market state in under 30 seconds and can inspect the full evidence chain

## Non-goals for v1.0

- Fully autonomous multi-channel campaigns without approval
- Replacing human setters/closers
- Cross-tenant intelligence
- Recreating intelligence logic in the UI

## Exit criteria

- SPEC-008 acceptance criteria pass (render-only Command Deck)
- SPEC-009 acceptance criteria pass (contextual Max workspace; no invented facts)
- SPEC-010 acceptance criteria pass (no dead ends; trail + related + company/recommendation views)
- SPEC-011 acceptance criteria pass (IntelligenceEvent, soft evolution, Max awareness, material notifications)
- SPEC-012 acceptance criteria pass (interaction events, outcomes, adaptive presentation, Max personalization, quality dashboard; deterministic stack unchanged)
- SPEC-013 acceptance criteria pass (recommendation outcomes, strategy metrics, calibration, drift, internal review; no reasoning/confidence mutation)
- SPEC-006 remaining acceptance covered via SPEC-010
- A new contributor can operate from docs + Command Deck without chat archaeology
- Constitution (approval, explainability, tenancy, DNC, cognitive load) enforced in the primary flows
- CURRENT_STATE reflects a stable v1.0 maintenance posture
