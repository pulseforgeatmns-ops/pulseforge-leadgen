# Release v0.7.1 — Knowledge Layer Foundation

| Field | Value |
|---|---|
| **Status** | Shipped (library package) |
| **Date** | 2026-07-26 |
| **Spec** | [SPEC-001A](../specs/SPEC-001A_Knowledge_Layer_Foundation.md) |

## Goals

- Prove knowledge domain model and service contracts without choosing a graph database
- Centralize graph mutations behind `KnowledgeService` + events
- Ship `explain()` as the foundation for Max answers

## Included

- `packages/knowledge/` with in-memory repository
- EvidenceEngine, ClaimEngine, KnowledgeEventBus, KnowledgeIngestor
- Unit tests (`npm run test:knowledge`)

## Explicitly not included

- Persistent storage
- Runtime wiring of Scout/Max/CRM
- UI / LLM / recommendations

## Upgrade / deploy notes

Documentation + library only. No migration. No production behavior change.
