## Goals

- Evaluate every recommendation against explicit, configurable policy rules
- Separate “what should happen” (reasoning) from “what is allowed” (policy)
- Produce explainable allow / warn / requireApproval / block decisions with audit trail
- Keep agents unwired; no automatic execution

## Included

- `packages/max/policy/` — PolicyEngine, RuleRegistry, seven rules, TenantPolicyStore, DecisionAggregator, PolicyAuditLog
- API: `policy.evaluate({ tenantId, recommendation, context })` and `max.decide(...)`
- Data-driven per-tenant policy configuration
- Tests under `packages/max/policy/tests/` (included in `npm run test:max`)

## Not included

- Automatic execution / outbox side effects
- Approval UI / notifications
- Adaptive / learning policies
- Runtime agent wiring

## Upgrade notes

Additive only. `createMaxReasoningRuntime()` now also returns `policy` and `decide()`. Existing `evaluate()` / `remember()` / `brief()` behavior unchanged.
