## Goals

- Assemble Knowledge + Reasoning + Memory into deterministic operator briefings
- Never compute new insight inside the briefing layer
- Support daily / weekly / monthly digests
- Add a Presentation Adapter extension point without owning UI

## Included

- `packages/max/briefing/` — BriefingEngine, BriefingBuilder, section builders, DigestBuilder, Prioritizer, PresentationAdapter
- API: `max.brief({ tenantId, asOf, period })` → structured `Briefing`
- Sections: summary, priorities, changes, watchAlerts, risks, recommendations, metrics
- Tests under `packages/max/briefing/tests/` (included in `npm run test:max`)

## Not included

- LLM briefing copy / email delivery
- Dashboard UI
- Runtime agent wiring (`maxAgent.js` unchanged)
- New reasoning strategies

## Upgrade notes

Additive only. `createMaxReasoningRuntime()` now also returns `briefing` and `brief()`. Existing `evaluate()` / `remember()` behavior unchanged.
