## Goals

- Translate CRM entities into knowledge ops through `KnowledgeService` only
- Idempotent, replayable, tenant-aware sync + relational rebuild

## Included

- `packages/knowledge/sync/` (`GraphSyncEngine`, mappers, ledger, relational sources)
- `ensureNode` / `ensureEdge` / `ensureEvidence` on the knowledge API
- Tests via `npm run test:knowledge`

## Not included

- Production dual-write wiring
- Persistent ledger / graph store

## Upgrade notes

Library-only. No migration. No production behavior change.
