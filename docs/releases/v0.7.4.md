# Release v0.7.4 — Knowledge Query Engine

| Field | Value |
|---|---|
| **Status** | Shipped (library) |
| **Date** | 2026-07-26 |
| **Spec** | [SPEC-001C Knowledge Query Engine](../specs/SPEC-001C_Knowledge_Query_Engine.md) |

## Goals

- Make the Knowledge Graph a queryable intelligence layer
- Expose a stable, typed, tenant-safe query API on `KnowledgeService`
- Identical behavior against in-memory and Postgres repositories
- No LLM / recommendations / agent wiring

## Included

- `packages/knowledge/query/` — QueryEngine, QueryTypes, Filters, Traversal, Timeline, Metrics
- KnowledgeService expansions: `findCompanies`, `findPeople`, `findInteractions`, `neighbors`, `related`, `timeline`, `path`, enhanced `explain`
- Query metrics instrumentation
- Tests: `packages/knowledge/tests/query.test.js` + Postgres parity in persistent suite

## Not included

- Agent/server dual-write
- Metrics dashboard
- Max Reasoning Engine (SPEC-002)

## Upgrade notes

Additive API only. Legacy `findEvidence(tenantId, query)`, `findClaims(tenantId, query)`, and `explain(tenantId, nodeId)` continue to work. Default runtime remains in-memory; agents stay unwired.
