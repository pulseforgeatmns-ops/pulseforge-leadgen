## Decisions and evidence

`opportunity-v1.0.0` is immutable configuration in `services/signalOpportunities/definition.js`, including its content hash. A rule or weight edit requires a new version. Decisions are append-only, timestamped in their own table. Historical decisions are never recomputed in place. No fitting against winners or REMUS occurs.

Every decision reports increases, decreases and unknowns. The initial score has explicit points for verified observations, documented independent convergence, rapid convergence, pool value, comparable price momentum, rolling volume acceleration and unique buyers where actually available. Correlated echoes, vertical extension, deteriorating liquidity, promotion divergence and Distribution V1 warnings reduce it. UNKNOWN gives no points. Pool reserve value is not established execution depth. Transaction counts are not unique buyers. Pool creation time is not token creation time.

HOT requires at least three documented independent clusters, five favorable dimensions, recent market observations and no scored negative evidence. Currently the DEX provider does not return unique buyers; the initial relationship registry contains no affirmative independence claims. **Consequently HOT is intentionally not reachable with the current production evidence coverage alone.** This is a disclosed coverage gate, not a reason to invent favorable inputs. Completing identity verification does not complete independence research.

Source sequences report first observed source, Telegram event time, knowledge time and prior empirical market cap where available. Later enrichment is never attached as historical call-time market cap. Lead/lag aggregates deduplicated tokens, requires at least ten observations for an association label and never claims causality. Front Runners is one source; pre-Front-Runners labels require observed prior knowledge and disclose unavailable amplifier coverage.

`measurement.js` accepts only completed, released, empirical prospective observations completed and known strictly before the evaluation time. It excludes blinded outcomes and promotional claims. Canonical ongoing research remains owned by the existing research pipeline; this live lane does not read its outcome tables. A scheduled read-only export selects only explicitly released, completed canonical observations; blinded outcomes remain excluded. Newly monitored sources may have no canonical samples.

## Operations

The worker reads retained real messages into immutable dashboard events, discovers new CAs without adding wallet positions, enriches up to 30 candidates per tick through the documented DEX Screener token-batch endpoint using shared provider budgets, evaluates bounded recent evidence and preserves every changed decision. Up to 120 recent candidates receive rotating market enrichment (a target cycle of 40 seconds before rate-limit or request deferrals). The dashboard reports deferrals. A high-volume universe may need larger legitimate provider capacity before freshness targets can be met. Current scoring freshness is 90 seconds; provider update-time freshness remains UNKNOWN.

The feed defaults to existing operation. Activation settings:

```
TELEGRAM_CALLER_EXPANSION_VERSION=source-universe-v1.0.0
TELEGRAM_CALLER_MAX_RETAINED_CALLS=5000
SIGNAL_OPPORTUNITY_ENGINE_ENABLED=1
SIGNAL_OPPORTUNITY_ALERTS_ENABLED=1
```

The last two variables belong on the isolated dashboard. SMS uses references to the existing Pulseforge `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER` and `OPS_ALERT_PHONE`. Email uses the existing Brevo account with explicitly configured `SIGNAL_OPPORTUNITY_EMAIL_FROM` and `SIGNAL_OPPORTUNITY_EMAIL_TO`. These values are never copied into source or logs. The additive dashboard migration owns two operational tables and is part of the existing approved pre-deploy migration workflow.

WATCH to OPPORTUNITY queues email. Any transition to HOT queues SMS and email. Held-token AVOID can queue email. OBSERVED and WATCH remain dashboard only. An hour cooldown is keyed per token/state/channel; HOT bypasses prior OPPORTUNITY alerts. Pending deliveries expire after five minutes and are suppressed if superseded. Atomic claims prevent replica duplicates. Ambiguous provider results become UNKNOWN and are not automatically resent. ACCEPTED means provider accepted, not delivered to the handset/inbox. No transport test creates research/source events.
